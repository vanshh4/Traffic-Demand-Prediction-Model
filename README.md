PROJECT TITLE

"Machine Learning-Based Mandatory Occurrence Report (MOR) Classification System for Flight Safety Reporting"

PROJECT BACKGROUND

The Flight Safety Department receives numerous occurrence reports written in plain English.

Currently, safety personnel manually review these reports and determine whether an occurrence qualifies as an MOR (Mandatory Occurrence Report), which must be reported to the DGCA.

This manual process is time-consuming, dependent on human judgment, and difficult to scale as reporting volumes increase.

The proposed project aims to develop a Machine Learning model that can analyze textual occurrence reports and classify whether they are likely to be an MOR or a Non-MOR.

The system is intended only as a decision-support tool and not as a replacement for safety experts. Final authority and responsibility for reporting decisions will always remain with Flight Safety personnel.
